# Contenido privado (soluciones y pruebas)

Este repositorio es público, así que aquí solo hay enunciados, plantillas,
teoría y pistas. Lo que revela respuestas vive aparte:

- **Dónde:** en un repositorio privado distinto (propuesto:
  `python-level-up-privado`), con la misma estructura de carpetas que
  `contenido/`.
- **Cómo se usa:** se clona dentro de `contenido_privado/`, carpeta que Git
  ignora en este repositorio. El servidor la localiza con la variable de
  entorno `PLU_CONTENIDO_PRIVADO`.
- **Qué contiene:** soluciones de referencia y pruebas de evaluación.

Estado: pendiente. El repositorio privado aún no existe.
