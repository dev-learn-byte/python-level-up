# contenido

Material público de estudio: teoría, ejemplos, misiones y pistas. Agregar
una saga es agregar una carpeta aquí, sin tocar el motor.

Las soluciones de referencia y las evaluaciones **no** van aquí: viven en
otro repositorio (ver `docs/contenido_privado.md`).

El formato de cada archivo está explicado en `docs/formato_del_contenido.md`.

## Qué hay

| Carpeta | Contenido |
|---|---|
| `sagas/01_entrenamiento_goku/` | Saga 1: tres niveles, 18 misiones y el jefe Maestro Roshi |
| `eventos/` | Misiones especiales opcionales, como la mazmorra de rango E |
| `diarias/` | Plantillas de la misión diaria |
